# ExcelToJson

Утилита для конвертации Excel файлов в JSON с графическим интерфейсом и встроенным редактором JSON.

## Возможности

- Конвертация Excel файлов (xlsx, xlsm, xls) в JSON на основе структуры: столбец A - ключи, столбец B - значения, столбец C - типы данных
- Поддержка различных типов данных: числа, строки, булевы значения, null
- Автоматическое копирование результата в буфер обмена
- Встроенный редактор JSON с проверкой синтаксиса
- Подсветка синтаксиса JSON
- Нумерация строк
- Поддержка тёмной и светлой темы (автоматическое определение темы Windows)
- Кроссплатформенность (Windows, Linux, macOS)

## Требования

- Python 3.7 или выше
- Зависимости из файла requirements.txt

## Установка

1. Клонируйте репозиторий:
git clone https://github.com/Dgecon/ExcelToJson.git
cd ExcelToJson

2. Установите зависимости:
pip install -r requirements.txt

## Использование

Запустите программу:
python ExcelToJson.py

### Конвертация Excel в JSON

1. В главном меню выберите "Конвертировать *.xlsx/*.xlsm в *.json"
2. Нажмите "Выбрать файл и конвертировать"
3. Выберите Excel файл
4. Результат сохранится рядом с исходным файлом с добавлением временной метки
5. JSON строка автоматически скопируется в буфер обмена

### Структура Excel файла

| Столбец | Назначение | Обязательный |
|---------|------------|--------------|
| A | Ключи (названия полей JSON) | Да |
| B | Значения (данные для полей) | Да |
| C | Типы данных (опционально) | Нет |

Первая строка пропускается (заголовки таблицы).

### Поддерживаемые типы данных

| Тип | Варианты записи в столбце C | Результат в JSON |
|-----|----------------------------|------------------|
| Число | number, int, integer, число, числовой | Число без кавычек |
| Булево | bool, boolean, логический | true/false |
| Null | null, none, пусто | null |
| Строка | string, текст (или пусто) | Строка в кавычках |

### Редактор JSON

1. В главном меню выберите "Исправление синтаксиса *.json"
2. Откройте JSON файл (Ctrl+O)
3. Редактируйте содержимое с подсветкой синтаксиса
4. Проверьте валидность (F5)
5. Сохраните результат (Ctrl+S)

#### Возможности редактора

- Подсветка ключей, строк, чисел, булевых значений и null
- Подсветка строк с ошибками
- Нумерация строк
- Перенос строк (опционально)
- Подсветка кириллических символов

## Горячие клавиши

| Окно | Клавиша | Действие |
|------|---------|----------|
| Главное меню | Ctrl+1 | Открыть конвертер |
| Главное меню | Ctrl+2 | Открыть редактор |
| Главное меню | Escape | Выход |
| Конвертер | Ctrl+O | Выбрать файл |
| Конвертер | Enter | Выбрать файл |
| Редактор | Ctrl+O | Открыть файл |
| Редактор | Ctrl+S | Сохранить файл |
| Редактор | F5 | Проверить синтаксис |

## Пример

Excel файл:

| A | B | C |
|---|---|---|
| name | Иван | string |
| age | 25 | number |
| active | true | bool |

Результат JSON:

{
  "name": "Иван",
  "age": 25,
  "active": true
}

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| Не удалось конвертировать файл | Убедитесь, что файл не открыт в другой программе и имеет правильный формат Excel |
| Ошибка в строке X | Проверьте синтаксис JSON в указанной строке, убедитесь, что все кавычки закрыты |
| Не копируется в буфер обмена | Установите pyperclip: pip install pyperclip |

## Зависимости

- openpyxl - работа с форматом xlsx
- screeninfo - определение положения курсора и мониторов
- pyperclip - работа с буфером обмена

Полный список см. в requirements.txt.
